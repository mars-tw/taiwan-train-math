# 小小列車長｜台灣火車數學樂園

給 **3–8 歲**小小鐵道迷的免費繁體中文網頁遊戲。陪星光高鐵送信到海邊，點開旅途小驚喜，再選喜歡的真實列車，練習數數、簡單加減、排序、規律、裝箱、記憶、時鐘、空間方向、分享與尋寶。

[直接遊玩](https://mars-tw.github.io/taiwan-train-math/) · [公開程式庫](https://github.com/mars-tw/taiwan-train-math)

## 可以玩什麼

- **3–4 歲**：1–5 數量與點點配對、列車名稱配對、三節車廂排序、AB 圖形規律、1–5 箱裝貨、兩對記憶翻卡；每趟三站。
- **5–6 歲**：0–10 數數、10 以內上車下車加減、列車配對、五節排序、數量比較、AAB／ABC 規律、10 箱內裝貨、三對翻卡及整點時鐘。
- **7–8 歲**：0–20 數數與加減、列車型號配對、排序與比較、跳數規律、20 箱內裝貨、四對翻卡及整點半點。跨十加減由家長開啟。
- **星光高鐵故事**：獨立透明列車沿山海軌道緩緩向下開，四段情節，可暫停、重播、手動換段和聽故事。點小鳥、燈塔與信封，直接進入故事任務。
- **三個新冒險**：旋轉軌道接通路線；把點心公平分給朋友，可隨時搬回；在風景裡找星星、葉子與貝殼。三種都依年齡調整，無時間壓力。
- 自由選車、山海地圖、暖陽／暮色、圖鑑搜尋、二十種單項練習與隨機驚喜旅程、本機鐵道護照、中文裝置語音、柔和音效與減少動畫。
- 完成旅程可拆開紀念信封，收藏三十六款旅途小禮物；不付費、不鎖遊戲、不限時收集。
- 驚喜旅程輪替適齡任務，記住最近玩過的題目；列車辨識會換車，排序與接軌也有不同組合。
- 加減題讀乘客紀錄、自己輸入答案。答對後才顯示結果；提示只教方法，不會直接報答案或自動做完。
- 完成後可以換台列車、玩新任務，也能搭同台列車練新題。無計時扣分，答錯可以再試。所有列車直接開放。
- **火車拼圖**：4／6／9 片，點一片再點位置，能取回、換片與主動看原圖；每站會換列車照片，自己拼好才完成。
- **行李分類站**：依年齡按顏色、形狀或兩個條件分類，放錯可以取回重分。**車站迷宮**有 3×3／4×4／5×5 不同路線，方向鈕或鍵盤都能玩。
- **旅途收藏冊**：六個主題、36 款小禮物，每趟可從新禮物中選一份，收齊主題有套組章。小禮物能點開玩，未領的份數和已開信封會留在本機。
- **手機與平板**：首頁有大按鈕，遊戲中縮短頂部、將送出放在下方。拼圖可拖放或點選，橫放與平板會並排顯示；數字題預設用畫面鍵盤，也可自行開啟裝置鍵盤。
- **稍後繼續**：回遊戲室或重新整理後，可接回同一分頁的原旅程與圖形操作。完成／清除紀錄後不會重複恢復；算術輸入不儲存。
- **四種新玩法**：指令小司機先排方向再出發；貨運天平選不同重量的箱子；圖形拼搭有十二種圖案及色塊；眼力找不同有四種車站風景。依三種年齡調整，提示不代做。
- **六條主題旅程**：森林、海岸、貨運、工程、野餐與車庫，各有不同任務組合及到站章；重玩會換題。
- **車票小幫手**：小難度替一張票付點數，中／大難度用同一盤有限代幣分配給兩張車票。拿錯可取回，沒有計時或扣分；答對才顯示總點數。使用遊戲代幣，票價單位為點。
- **照片重新載入**：拼圖、翻卡或認車照片未準備好時先顯示狀態；載入失敗可重試，保留原題與已放好的位置，不換成別款列車。

收錄 **59 個車型、車號系列與列車名稱條目**：台鐵主要動力車型、高鐵 700T、阿里山林鐵、觀光與糖鐵列車，以及日本 E5、N700S 子彈列車、L0 磁浮試驗列車。N700ST 標為已抵台、尚未營運。[完整收錄範圍](docs/catalogue-coverage.md)。

**58 筆圖鑑照片已核對實車及授權。** 列車介紹附原作者、授權、來源與車號證據；兩筆內裝照片及歷史塗裝另行標示。LDK59 尚待可確認型號及授權的照片，顯示待補，不借其他車號代替。辨識、翻卡及拼圖只使用已核對的外觀照片；DR1000／DRC1000 同型別名不重複出題。直幅 E1000 保留在圖鑑和配對，拼圖選用適合橫向格子的完整照片，避免出現難分辨的空白片。31 張既有 AI 插圖保留給想像故事、風景及舊旅程相容，與實車教材分開。[逐張照片授權](docs/train-photo-credits.md)。這不是逐輛現役車籍或營運時刻表。

## 在自己的電腦執行

需要 Node.js 20 以上。無執行期套件依賴，無須 `npm install`。

```sh
git clone https://github.com/mars-tw/taiwan-train-math.git
cd taiwan-train-math
npm run dev
```

開啟 **http://127.0.0.1:4173**。請用伺服器開啟，不要直接雙擊 index.html；瀏覽器模組與 JSON 載入需要 HTTP。

在同一 Wi-Fi 的手機或平板試玩：

```sh
npm run dev -- --lan --port 4186
```

使用終端機列出的家庭網路網址，保持電腦與預覽程式開著。手機不要用 `127.0.0.1`。[手機試玩說明](docs/mobile-preview.md)。

```sh
npm test
npm run build
node scripts/serve.mjs --dist
```

`dist/` 可放到一般靜態主機。手機瀏覽公開網址即可，不需要安裝 App。首次載入需要網路，尚未提供離線快取。

## GitHub Pages

本儲存庫已啟用 GitHub Pages，公開網址可以直接遊玩。自行 fork 時，管理者在 **Settings → Pages → Build and deployment → Source** 選 **GitHub Actions**。推送 main 會執行測試、建立靜態檔案並部署；也可在 Actions 的 **Test and publish game** 手動執行。

首次啟用是 GitHub 儲存庫的主機設定。若未啟用，公開程式庫仍可下載與本機遊玩，但 Pages 網址會顯示 404。

## 專案結構

- `src/app.js`：畫面、遊戲互動、語音與本機護照。
- `src/home.js`／`src/immersive.css`：可探索首頁及新玩法美術。
- `src/activities.js`：規律、裝箱、翻卡及時鐘的可操作教材畫面。
- `src/story.js`／`src/story-model.js`／`src/story.css`：四段故事、實際列車動畫與動畫生命週期。
- `src/adventure.js`／`src/adventure-ui.js`：鋪軌、點心分享、尋寶及旅途禮物。
- `src/engine.js`：分齡題目生成、答案檢查、儲存容錯。
- `src/arithmetic-ui.js`：不透露總人數的加減作答區與數字輸入驗證。
- `src/puzzle.js`／`src/puzzle.css`：分齡照片拼圖、選取、換片與原圖預覽。
- `src/explorers.js`／`src/explorers.css`：行李分類與車站迷宮。
- `src/rewards.js`／`src/souvenirs.css`：待領小禮物、固定選項、收藏冊與互動小物。
- `src/mobile.css`／`src/puzzle-touch.js`：手機／平板畫面、觸控拖放與手勢取消。
- `src/trip-session.js`：同分頁的旅程生成配方、操作保存與恢復。
- `src/tickets.js`／`src/tickets.css`：共用有限代幣的車票分配；`src/photo-loader.js`：照片狀態、重試及過時回應隔離。
- `src/workshop.js`／`src/discovery.js`：指令、天平、拼搭、找不同；`src/journeys.js`：六條主題旅程。
- `src/train-images.js`：照片資格、型號別名去重及舊圖片相容；`data/train-photos-*.json`：逐張車號、來源、授權與 SHA-256。
- `data/trains.json`：車型、介紹、分類、實車照片及來源；`questions.json` 為初始題目範例，實際遊戲由引擎生成。
- `assets/images/`：實車照片與想像 WebP 圖片；`assets/manifest.json`：AI 生成提示與授權紀錄。
- `docs/`：[遊戲規劃](docs/game-plan.md)、[素材設計](docs/assets.md)、[首頁美術規劃](docs/art-direction-v2.md)、[故事與新冒險規劃](docs/story-adventure-v3.md)、[工作清單](docs/tasks.md)、[來源與授權](docs/sources-and-licenses.md)、[驗證紀錄](docs/validation.md)。
- `tests/`：題目與資料驗證。
