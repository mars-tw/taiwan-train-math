已讀共用核心規則、token-efficient-ai-dispatch、game-optimization-round、上層 CLAUDE.md、本 repo README、R1 計畫與 R1 報告。本 repo 沒有 AGENTS.md、CLAUDE.md、docs/AUDIT_full.md。僅處理本 repo，全程背景／headless；不 push、不部署、不碰商店。原有三份 store-listing 審查備註保持原狀、不提交。

## 可驗收工作

1. **深度內容**：新增四章、每章三個學習任務，三種年齡各自累積，共 36 個可完成目標。從遊戲室進入，直接啟動適齡題目；完整完成一趟才推進一格，提示與重試不扣獎勵，離開／重載可續玩。每三個目標取得一枚章，護照可讀回；完成頁可直接開始下一個目標。所有原玩法維持開放。
2. **兒童觸控**：新按鈕至少 48px；遊戲返回固定可點；手機主要答案與下一步留在底部。390×844、844×390、1366×600 與 1280×640 驗證控制可達、命中尺寸、遮擋、橫向溢出與文字裁切。若內容較多，題目內可捲動，頂部返回與底部答案始終可用。
3. **版本 workflow**：ios-store-screenshots 從 package.json 讀取預期 Web 版本，回報實際 manifest 版本；保留來源 run／SHA／ZIP 雜湊驗證，不觸發 workflow。舊 artifact 與新版不符時必須拒收，不為通過而放寬來源驗證。
4. **測試證據**：先保存 before 直橫手機截圖；新增任務生成、解鎖、冪等、儲存與備份測試，以及 headless 完整完成／暫停續玩／獎勵讀回／控制可達性 E2E；保留既有斷言。保存 after、JSON 量測及測試輸出到 docs/evidence/r2-mobile/。
5. **品質收尾**：npm test、既有 Python 回歸、Web/native build 與驗證；舊 Web 版本僅留歷史與存檔相容；指定秘密字串掃描零命中。效能如量測，一律標「並發載量測，僅供參考」，不宣稱出貨效能閘通過。繁中報告 docs/CODEX_RESPONSE_R2_MOBILE.md，明確路徑 git add、本機繁中 commit。

## 八大面向

| 面向 | 本輪做／不做與理由 | 證據／驗收 |
|---|---|---|
| 美術 | 做既有色盤的任務冊 UI；不新增原畫，沒有可指定 gpt-image-2 slug 的工具，不用方塊冒充 | before/after；缺件表 |
| 按鈕 | 做 48px 兒童目標、固定返回、底部作答與橫向配置 | 四視口可達性 E2E |
| 選單 | 做單卡章節進度、下一任務捷徑與護照收藏，避免一次攤開 36 項 | 進入／完成／返回／重載 E2E |
| 人物 | 不改既有人物，本輪聚焦學習與收集 | R1 人物與色票測試不刪不放寬 |
| 地圖模型 | 不新增場景或模型，任務使用現有真實列車照片與教材 | 既有圖片授權與生成測試 |
| 技能 | 做數學任務成長、逐章解鎖與完成回饋，無消耗型技能 | 三分齡 36 目標生成、完成防重複測試 |
| 腳色樣子 | 不改角色美術，無新角色需三視圖 | 保留既有色票閘 |
| 動作流暢度 | 保留現有逐步演示與減少動畫，不新增假角色動畫 | 既有 playback／reduced-motion 回歸 |

## 既知限制

- DevSpace chatgpt_list_workers 實際回傳 Internal error，尚無可驗證的外部對話接單；本機 deterministic 實作驗證繼續，獨立覆核能力缺口會記錄。
- 不做實體手機／兒童試玩、不執行 iOS Simulator 或商店操作。
- iOS capture 仍釘選舊 run 與已驗證 hash。改為讀目前版本後，新版不能拿舊 artifact 冒充；更新來源契約另列缺件。
- 不新增未確認授權的音樂／音效；使用既有回饋。
