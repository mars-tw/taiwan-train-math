# 首頁美術與互動規劃 · v1.1.0

更新日期：2026-10-04。對象：3–8 歲孩子及照顧者。已實作的設計與後續親子驗證分開記錄。

## 核心體驗

首頁是一座可探索的「山海鐵道樂園」。孩子點小站、挑喜歡的列車，再按出發；每次旅程有三站或五站。場景由台灣山林、海岸、鐘樓站房、貨運木屋及扇形車庫構成，是想像的教育場景，頁面明示不是實際路線圖。

桌面把四個任務入口放在場景地標上；手機將入口排成兩欄大按鈕，避免細小地圖熱點。每個入口顯示地點與玩法，選擇後有明確預覽及「搭車去這裡」按鈕。地圖和下方任務卡共用適齡規則及目前列車；任務卡明示「立即出發」，點選即可開始，無須再回到上方登車證。

## 美術基調與圖層

真實電影風環境配清楚、溫暖的操作介面。保留原有列車素材；數量、形狀、時鐘採 HTML／SVG 示意，確保數學圖像精確而且可操作。

| 層次 | 素材／用途                       | 規格                                 |
| ---- | -------------------------------- | ------------------------------------ |
| 遠景 | 山脈、海岸及高鐵高架線           | 靜態電影風全景，不循環自動播放       |
| 中景 | 鐘樓、木造貨運站、車庫、海邊月台 | 地圖入口呼應畫中建築；不宣稱實際位置 |
| 遮罩 | 左側深綠漸層與底部遮罩           | 白色標題清楚；暮色以 CSS 調色        |
| 操作 | 四個車站標記、氣氛切換、進站鈴   | 點選／鍵盤可操作，不依賴滑過         |
| 任務 | 登車證、精選列車、九種任務卡     | 顯示目前選車、年齡難度及任務         |
| 教材 | 圖形車廂、木箱、翻卡、類比時鐘   | 數量可查核；顏色同時有形狀或文字提示 |

主要色彩：森林深綠 `#203d38`、米白 `#faf8f1`、暖金 `#edaa61`、紙票 `#f6f0d9`。避免用強烈閃爍、紅色失敗畫面、倒數壓力或大量自動聲音。暖陽／暮色代表場景氣氛，不代表真實時間或天氣。

## 新增玩法與分齡

| 玩法         | 3–4 歲                   | 5–6 歲                  | 7–8 歲                       |
| ------------ | ------------------------ | ----------------------- | ---------------------------- |
| 規律小火車   | AB 兩種圖形重複          | AAB 或 ABC 圖形規律     | 每次加 2 或 3，答案不超過 20 |
| 貨物裝箱     | 1–5 箱，目標同時顯示箱子 | 1–10 箱，逐箱放入或搬回 | 1–20 箱，可一次放 5 箱       |
| 列車記憶翻卡 | 2 對／4 張               | 3 對／6 張              | 4 對／8 張                   |
| 車站時鐘     | 提示切換適合的難度       | 1–12 點整               | 整點及半點                   |

記憶卡每組使用不同列車圖片，避免共用家族素材造成混淆。翻到不相同的卡會留在畫面，孩子自己按「再試一組」，不會突然蓋起來。提示可以看全部卡，再自己配對；只有配對完成才進入下一站。

裝箱可以點貨物搬回、全部重放或提交答案；上限為當前年齡的 5／10／20 箱。時鐘的短時針在半點會移到兩個時數中間，長分針指向 6；兩種針同時用長度、顏色與文字區別。

驚喜旅程固定包含數數與所選列車辨識，中間任務從適齡玩法隨機挑選，不重複。單項練習則重複所選玩法三站或五站。

## 互動、聲音與可及性

- 選站後保持焦點與畫面位置；按出發有約 420ms 的輕微推進，再進入題目。
- 家長「減少動畫」或系統 reduced motion 任一開啟，就直接進入題目；沒有必要的循環動畫。
- 進站鈴只在按鈕點選後播放，沿用 Web Audio 柔和提示音；家長關閉音效後停用鈴聲入口。語音仍預設關閉。
- 任務卡、車站入口與主要操作至少 44px 高；保留清楚的鍵盤焦點、ARIA 選中狀態及操作公告。
- 不自動把幼兒模式切換到較高難度；時鐘、加減與比較入口會說明適合 5–8 歲，引導家長選擇。
- 本機護照沿用 v1 的儲存格式與鍵名，既有紀念章和旅程數可繼續使用。

## 後續親子驗證

請實際觀察三個年齡組：能否理解「點小站 → 出發」、箱子能否正確一個算一個、是否會使用翻卡的重試按鈕、半點是否需照顧者講解。紀錄卡住的位置與原因，不收集孩子的個資。Safari、實體手機與幼兒觸控操作尚需實測，工程驗證記於 `docs/validation.md`。
