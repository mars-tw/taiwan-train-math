# 素材與美術設計

## 已製作素材

v1.7 新增逐張核對的實車照片，清單見 [照片來源與授權](train-photo-credits.md)。圖鑑、找火車、記憶翻卡及新拼圖改用 `real-*` 圖檔；圖片完整呈現車頭與車身，內裝、歷史塗裝及尚未營運的列車明示。來源或授權無法確認時顯示待補，不用其他型號代替。

原有 31 張 ImageGen 電影風情境插圖輸出 WebP，總計約 6.4 MiB，保留給想像風景、故事與 v1.5／v1.6 未完成旅程相容，不再作為新車型辨識教材。

完整生成提示、尺寸、檔案、作者與授權見 [assets/manifest.json](../assets/manifest.json)。生成原圖保留在生成工具原輸出位置，專案收錄壓縮版；只改尺寸與壓縮，不添加官方文字與商標。

v1.2 新增透明白金色星光高鐵與無車山海背景，列車和背景獨立合成，車頭朝畫面下方。星光高鐵為想像故事車，不代表實際 700T 外觀。詳見 [故事與新冒險規劃](story-adventure-v3.md)。

保存蒸汽列車追加 steam-main 家族插圖，收錄 CT273、DT668、CK124、CK101、LDK59 車號，並清楚標為保存車。

## 介面與聲音

- 介面色系：米白、森林綠、暖橘；內文使用裝置繁中文字型，不外連字型服務。
- 數學乘客為程式生成 SVG，車票為簡單符號，排序車廂為 CSS 示意。這些避免寫實場景中數量模糊或遮擋。
- 圖片之外提供文字名稱與型號；聲音由裝置中文語音朗讀，沒有再散布第三方錄音。
- 成功音效由 Web Audio 合成三個柔和音符，可關閉。
- 第一次遊玩語音關閉，以家長設定或聽題目開啟朗讀。瀏覽器沒有中文語音時可看畫面完成。

## 後續素材工作

優先替各家族製作分型插圖與細節校對、為幼兒試作注音、測試不同裝置朗讀，視試玩結果製作自有配音。新增素材必須有作者、來源與可散布授權。

首頁新圖與九種玩法的圖層、色彩、聲音及分齡規格見 [美術與互動規劃](art-direction-v2.md)。
