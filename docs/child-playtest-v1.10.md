# 兒童操作情境模擬與教材改善

2026 年 10 月 6 日，對應 v1.10.0。由不同 AI 工作上下文按指定的閱讀、數學熟悉度與操作策略進行審查，再用真實瀏覽器做可重現操作。沒有招募兒童、測量 IQ 或測量學習成效；腳本成功不代表兒童一定成功，也不把年齡當作智力分級。

## 模擬條件

| 情境 | 限制與熟悉度 |
| --- | --- |
| A：3–4 歲初次玩 | 辨認 1–5 與圖示，不假設能讀長句，一次只給一個動作。 |
| B1：5–6 歲需多協助 | 可讀短句，加減初學；不假設先知道按鈕和容器的操作順序。 |
| B2：5–6 歲較熟悉 | 可讀兩步說明，能自行數圖，加入連點、選錯和取回情境。 |
| C1：7–8 歲初學 | 數學與觸控仍不熟；同齡可以需要較多操作協助。 |
| C2：7–8 歲獨立操作 | 可自行計算，熟悉列車名詞；可略過方法提示，直接選玩法。 |

裝置為 320px、390px 手機、768px 平板、844px 手機橫向、1440px 鍵鼠桌機的瀏覽器模擬；使用 Chromium 及 WebKit。不是實體 iPhone、iPad 或 Android 驗收。

角色作答只用可見乘客、運算紀錄、車票面額、照片、圖形和按鈕。驗證器可讀儲存內容核對續玩，但不能用內部 `q.answer`、路線解法或藏牌位置替模擬角色作答。語音檢查比對待朗讀文字，未冒稱實際揚聲器或每台裝置的中文聲音都已測試。

## 找到並修正的負擔

| 原本情況 | 原因 | 改善 |
| --- | --- | --- |
| 每站常換控制，先讀整段才知道按哪裡 | 第一次玩同時要學數學與控制規則 | 第一趟主要入口練同一種數數；每題有一行「這一步」，聽題目包含操作方法。仍可直接自己選二十種玩法。 |
| 「已點過 N 位」及自動朗讀累計數 | 孩子只要點完就可抄總數 | 未答前只留 ✓ 記號，由孩子自己數；答對才顯示總數。加減的未知結果也保持隱藏。 |
| 手機按提示後看不到文字 | 固定送出按鈕擋住畫面，文字又在長內容後方 | 提示與狀態放到操作區整行，依實際高度保留捲動空間；桌機僅在回饋超出畫面時最小捲動。 |
| 迷宮撞牆只在隱藏朗讀區提醒 | 靜音或不讀文字的孩子看不到原因 | 顯示可見撞牆說明，保留位置及回頭機會。 |
| 拼圖空格沒選片仍像是成功、排序空位沒反應 | 回饋與實際操作不一致 | 明示先選片／先選數字，操作完成後改為提醒自行檢查，不判定正確位置。 |
| 初態籃子寫「放進這裡」卻不能按 | 還沒先選行李 | 籃子先寫「先選行李」，選好後才提示放入。 |
| 點心每人一份已相同，但籃子還有剩 | 「一樣多」和「全部分完」是兩個條件 | 同時說清兩個條件；只依是否分完開放檢查，不先替孩子判斷公平份數。 |
| 型號術語、別名和故事風景容易混淆 | 成人介紹過長，真實感插圖容易被當成真地點 | 圖鑑先呈現一短句、細節收合；DR1000／DRC1000明示同型；首屏標想像故事，完成後另讀有來源的真實台灣小知識。 |

## 教材與驗證範圍

二十種玩法都有短目標、可見動作、方法提示及完成後概念句。提示模組不讀答案、卡牌配對、最佳路線或解法，不改孩子的操作。舊版題庫配方維持 `contentVersion: 1.8.0`；護照、禮物和 1.5–1.9 未完成旅程保留。

小發現涵蓋 59 個車輛 ID（DR1000／DRC1000 共用同型內容），及阿里山、奮起湖、龜山島、高美濕地、蒜頭糖廠、彰化扇形車庫。每次一張短卡；真實地點明示區域，不暗示該列車行駛至此，也不借想像圖片當實景。[教材與官方來源](../src/learning-content.js)。

本輪跨兩引擎實際檢查二十種玩法的提示位置、點擊範圍、溢出及未解狀態；另完成數數、翻卡、分類、拼搭、加減與認車代表流程，確認錯誤可重試、首旅同玩法、退出／重整續玩及獎勵不重複。確切檢查與限制見 [驗證紀錄](validation.md)。

設計參考 [IES 幼兒數學教學指南](https://ies.ed.gov/ncee/wwc/practiceguide/18) 的循序概念與建立在已會知識上的教學，以及 [NAEYC 科技與互動媒體立場](https://www.naeyc.org/resources/topics/technology-and-media-0/technology-and-interactive-media-position-statement) 的個別需要與成人共同參與。這些資料未驗證本遊戲的學習效果；實際效果仍需親子試玩。
