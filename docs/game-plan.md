# 遊戲規劃：小小列車長

## 目標與對象

給台灣 3–8 歲兒童與照顧者的免費火車數學遊戲。孩子可以挑喜歡的車，認識名字與型號，透過點乘客、加減人數、排車廂練習簡單數學。以繁體中文、大按鈕、圖像與可選語音降低閱讀門檻。

## 分齡設計

| 難度       | 年齡參考 | 任務                                                 |
| ---------- | -------- | ---------------------------------------------------- |
| 小小站長   | 3–4 歲   | 1–5 點點配對、兩張列車卡配對、三節車廂排序           |
| 火車助手   | 5–6 歲   | 0–10 數數、10 以內加減、名稱配對、五節排序、票數比較 |
| 小小列車長 | 7–8 歲   | 0–20 數數與加減、型號配對、連續數排序、票數比較      |

年齡僅作選擇參考；家長依孩子理解程度切換。7–8 歲預設控制跨十難度，可額外開啟跨十挑戰。3–4 歲一趟三站，其他模式五站；可選擇單項玩法練習。

## 遊戲流程

首頁看星光高鐵的想像故事 → 出發小站或四分類遊戲室 → 選喜歡的列車與合適難度 → 每站完成一個任務 → 看一句數學概念與旅途小發現 → 收集紀念章及小禮物 → 再玩或休息。第一次新護照的主要入口先練同一種數數玩法，每站換題；已完成旅程的護照保留驚喜輪替。孩子也能直接自己選遊戲。

圖鑑提供分類、名稱／型號搜尋、介紹、朗讀與官方來源。每個條目直接開放，不透過付費或答題鎖車。旅程途中可以返回選車。語音、音效與動畫皆可調整。

## 二十種玩法

1. **數數看**：點乘客留下記號，一位自己數一次，再選答案。不在作答前自動報累計數；答對才顯示總數。幼兒用兩個點點選項，大孩子看數字，包含零人。
2. **找火車**：按題目找名稱或型號。每題選項避免相同名稱、相同型號及共用圖片，降低混淆。只有真正型號條目才出型號題；觀光名稱、車號系列出名字題。
3. **上車下車**：看原有人數和上／下車紀錄，自己算並輸入結果。未知總數不畫成乘客，不給結果選项；答對才顯示完整算式。人數不為負，不超過分齡上限。
4. **排車廂**：點數字車廂，從小到大放入位置；可點位置取回或全部重排。三節／五節各有規則。
5. **比一比**：左右兩組車票，選左邊、右邊或一樣多。

6. **規律小火車**：幼兒 AB、5–6 歲 AAB／ABC 圖形規律，7–8 歲加 2／3 的跳數。
7. **貨物裝箱**：親手放入或搬回貨物，對照目標；數量限 5／10／20，較大孩子可一次放 5 箱。
8. **列車記憶翻卡**：找 2／3／4 對相同列車；不同圖片，錯配後自己決定何時重新蓋卡。
9. **車站時鐘**：5–6 歲整點，7–8 歲整點半點；SVG 時針依分鐘正確偏移。

10. **路線小工程師**：旋轉軌道，接通起點與小站；分齡三／五／七段有效軌道。
11. **列車點心派對**：把全部點心公平分給兩或三位朋友，拿錯可搬回。只在籃子分完後開放檢查，不替孩子判斷正確份數。
12. **山海尋寶**：在風景裡找指定數量的星星、葉子或貝殼，不重複計算已找到的物件。

13. **火車拼圖**：4／6／9 片，點一片再點位置，也能拖放；原圖由孩子主動打開，不自動拼好。
14. **行李分類站**：按顏色、形狀或兩個條件分類。先選行李，再選籃子；放錯可取回。
15. **車站迷宮**：方向鈕直接走一格；撞牆顯示可見說明，可以回頭。
16. **指令小司機**：先排方向，再按出發逐格走；可以停車、刪指令與重排。和迷宮的控制規則明確分開。
17. **貨運天平**：搭配不同重量的貨物；按檢查才顯示重量方向，答對才報總重量。
18. **圖形拼搭**：對照小圖，按色塊和位置作畫；有橡皮擦及取回，保持孩子自己比對。
19. **眼力找不同**：比較兩幅車站風景，逐區點右圖。提示不標出正確區域。
20. **車票小幫手**：看每枚代幣的點數，替一／兩張票付款；拿錯可取回，不先顯示總額、差額或正確搭配。

完成旅程後可拆開紀念信封，收藏六主題、36 款小禮物。詳細規格見 [故事與新冒險](story-adventure-v3.md)、[拼圖與禮物](playroom-and-gifts-v1.4.md) 及 [試玩改善](child-playtest-v1.10.md)。

所有玩法無倒數、扣分、排行榜。每題顯示短目標和一個操作步驟；孩子主動按提示時只教方法，完成旅程即可集章，提示不取消獎勵。提示及錯誤訊息在手機底部操作區可見，桌機只做必要的最小捲動。難度由家長依理解程度選，不依年齡判斷智力。

## 列車與教材範圍

第一版納入 59 個主要車型、車號系列與服務名稱，完整表在 [收錄範圍](catalogue-coverage.md)。台鐵、高鐵、林鐵與觀光內容為主，追加孩子喜歡的海外子彈列車與磁浮試驗車。

「台灣現有車種」在教材中整理為可查核的車型與名稱清單，非逐輛即時車籍。型號、車號系列與觀光名字分開標示；既有車輛可能逐步除役。未來 N700ST 不標成現役。捷運、輕軌、所有工程與貨車細目不在本版範圍。

## 美術與操作

圖鑑、認車、翻卡及拼圖使用已核對的實車照片，LDK59 尚待照片；各筆照片保留原授權。31 張 AI 圖像用於想像故事與風景，不當成特定真實地點。數學乘客、車票與車廂採簡單示意，保留清楚數量與可操作性。

首頁保留山海故事首屏，只有驚喜／起步旅程和自己選遊戲兩個主要入口；六條故事旅程預設收合。答對後的小發現涵蓋 59 個車輛條目及六個真實台灣地點，明示來源與地區；閱讀主題不代表列車實際路線或照片拍攝地點。圖鑑先用一句短介紹，成人細節可展開。

支援滑鼠、觸控、鍵盤點選、焦點提示、朗讀與減少動畫。對幼兒閱讀能力的適配需要親子實測，第一版先提供圖像與朗讀協助。

## 技術與發布
