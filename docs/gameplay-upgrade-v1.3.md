# 玩法調整：自己算，下一趟有新發現

日期：2026-10-05。根據親子試玩回饋修改重複題目和過度提示。

## 算術題

題目只顯示原有人數、上車或下車的人數與待填算式。孩子自行按數字鍵或輸入答案，沒有事先算好的乘客群，也沒有答案選項。按 Enter 或「算好了，送出」作答；空白不能當作零，負數、小數與超出本難度範圍的輸入不接受。

答錯可以繼續試，沒有計時扣分或自動揭曉。主動按提示時，只說明上車用加法、下車用減法。答對後才顯示算式結果與最終人數。3–4 歲維持數數與操作遊戲，不新增算術；7–8 歲仍由家長決定是否開啟跨十加減。

## 新題與新旅程

- 混合旅程優先選比較久沒玩過的適齡任務，再調整順序；每趟三／五站、同趟不重複任務類型。
- 單項練習維持所選玩法，變換題目。題目紀錄依實際內容判斷，換選項順序不算新題。
- 列車辨識輪替有不同名稱和圖片的目標，不綁定目前搭乘的列車，排除未來規劃車型與含糊的同圖候選。
- 排序改用年齡範圍內不同數字集合；接軌保留原尺寸與可解性，小／中模式增加不同路線。
- 完成後可選「換台列車，玩新任務」或「同台列車，再練新題」。換車優先選尚未集章且圖片不同的列車。
- 最近題目與任務只存在本機，數量有上限；題庫有限，用完後會再練最久前的題目。重新整理保留紀錄，舊版存檔不清除。

## 提示文案調整紀錄

依 core-rules 的 `speak-human-tw` mode 2 直接套用。

| 原句／行為 | 原因 | 改成什麼 |
| --- | --- | --- |
| 「看乘客移動，一起練習加減。」 | 舊玩法以答案人數作動畫，與新作答方式不同。 | 「讀乘客紀錄，自己算出上車下車的人數。」 |
| 加減提示：「起始人數 加／減 變化人數 是 答案。看留下來的乘客，一起數數看。」 | 提示已把答案報出來。 | 說明上車讓人數增加、下車讓人數減少，孩子自行計算。 |
| 數數提示：「每位乘客點一次，一起數到總人數。」／「月台還沒有乘客，所以是零人。」 | 直接報總數，且提示會自動點滿。 | 每位只數一次、可做記號，自己確認總數；提示不改點選狀態。 |
| 規律提示直接說「就是答案」或「再從正確形狀開始」。 | 直接指出下一節。 | 比較相鄰數字的差，或找重複小組與空位位置。 |
| 時鐘提示報出「某點整／某點半」。 | 直接朗讀正確選項。 | 先看短時針，再看長分針，自己分辨整點與半點。 |
| 排序提示指明最小數字，再附整個正確順序。 | 幫孩子完成排序。 | 自己找剩下數字中最小的，依序排好。 |
| 比較提示報出左右兩邊張數。 | 跳過孩子數數和配對的過程。 | 一張一張配對，看看哪邊還有剩下的。 |
| 找火車提示重複正確車名和型號。 | 缺少可用的辨識方法。 | 看車頭、車身，再對照題目名稱或型號。 |
| 軌道提示：「亮起的線是參考路線。」 | 新版提示不再亮出解法。 | 「從起點跟著軌道走，檢查兩格交界的鐵軌有沒有接在一起。」 |
| 連錯兩次自動顯示提示。 | 孩子還在思考就被介入。 | 保留重試，提醒需要時可主動按提示。 |
| 完成頁：「再坐一趟」。 | 沒說明是否換車或換題。 | 明確提供換車新任務，以及同車新題兩種選擇。 |

驗證結果另見 [驗證紀錄](validation.md)。
