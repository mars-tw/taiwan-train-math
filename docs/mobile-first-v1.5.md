# 手機與平板玩法調整

日期：2026-10-05。保留十五種玩法與原有護照，把兒童的手機／平板操作作為主要情境。

## 找到遊戲與操作

手機首頁直接提供驚喜旅程、拼圖、分類與迷宮；「看看所有遊戲」直接到完整玩法區，不必先看完故事或捲過地圖。難度在家長設定更換。

遊戲中縮短頂部，主要按鈕至少 48 CSS px。答案、送出、錯配重試、分享重分等放在下方作答區，保留文字與圖示。拼圖／迷宮在平板與橫向使用並排空間，不鎖定橫直向；瀏海與下方操作區保留安全空間。瀏覽器可縮放，沒有停用使用者放大。

觸控選取與放置時保留目前捲動位置，鍵盤使用仍維持焦點。貨物加載和分享控制保持在清單前，數量增加時不把按鈕推離畫面；物件較多可以在清單內捲動。數字題用畫面按鍵，主動選「使用裝置鍵盤」才開啟可編輯欄位。

## 拼圖拖放

移動超過 9 px 才算拖曳，放到手指實際指向的格子。保留點片再點格與鍵盤 Enter，照片不會自動吸到正確位置。拖到板外、取消、多指、捲動或畫面切換時保留原位置，視覺拖影會清除。

驗證發現 Chromium 在觸控拖曳後的一小段時間可能不產生相容 click。拼圖使用同一按鈕既有路由處理手指點選，抑制同一手勢的第二次 click，避免漏按或放兩次。滑鼠與鍵盤維持原本流程。

## 續玩與資料

「回遊戲室」會保留同分頁原旅程。重新整理後也可選「繼續玩」，保留題目、拼圖、分類、點選記號與迷宮位置。算術輸入與錯答紀錄不保存；關閉分頁不保證保留暫存。

只保存生成種子與配方，以原題庫重建，不把存檔中的任意題目文字帶進畫面。完成後先清暫存再計一次旅程與禮物。家長清除紀錄也清掉目前與暫停旅程；更換難度後再練會使用合法的玩法，不把加減題帶入 3–4 歲模式。

## 聲音與鍵盤

首次手指互動恢復裝置音訊；切到背景停止語音、暫停音效。聽題目只讀題目，提示只說方法，答錯不朗讀總數。

原生鍵盤可能改變可見範圍，所以使用 [VisualViewport](https://developer.mozilla.org/en-US/docs/Web/API/VisualViewport) 調整下方作答區；使用者縮放時保留正常縮放。全螢幕依 [Fullscreen API](https://developer.mozilla.org/en-US/docs/Web/API/Fullscreen_API) 能力顯示，沒有支援時仍可直接玩。拖曳依 [Pointer Events](https://developer.mozilla.org/en-US/docs/Web/API/Pointer_events) 管理單指、多指與取消。

## 手機實際試玩

用 `node scripts/serve.mjs --lan --port 4186` 啟動，同一 Wi-Fi 手機／平板開終端機列出的家庭網路網址。電腦和預覽程式保持開著；使用手機自己的 `127.0.0.1` 無法連到電腦。詳見 [手機試玩說明](mobile-preview.md)。

工程驗證包含 Chrome 真正的觸控模擬、五種尺寸共 75 個玩法組合，以及 Windows WebKit 引擎代理。這些不等同於實體 iPhone／iPad 或 Android 的音訊、軟鍵盤與 Windows 防火牆實測。本版仍是本機／家庭網路預覽，GitHub Pages 尚未更新。

## 文案調整紀錄

依 `speak-human-tw` mode 2 直接套用。

| 原句 | 原因 | 改成什麼 |
| --- | --- | --- |
| 「← 返回選車」 | 回去後原關卡消失，手機容易中斷。 | 「← 回遊戲室」，保留旅程並提供「繼續玩」。 |
| 「按數字，或用鍵盤輸入。」 | 觸控裝置應先用遊戲內的數字鍵。 | 「按下面的數字鍵，輸入你算出的人數」，另有裝置鍵盤選項。 |
| 「先點一片拼圖，再點上面的空格。」 | 加入手指拖放，仍保留點選。 | 「拖一片到空格，或先點一片再點空格」。 |
| 「再試一組」在翻卡下方。 | 錯配後按鈕可能離開手機可見區。 | 維持同句，移到下方作答區。 |
| 「全部放回籃子」。 | 操作區需要短而明確的標籤。 | 「重分」，輔助標籤仍說明全部放回。 |

驗證數據見 [驗證紀錄](validation.md)。
