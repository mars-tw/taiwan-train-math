# 用手機、平板在同一個 Wi-Fi 試玩

在專案資料夾開啟終端機，執行：

```powershell
node scripts/serve.mjs --lan --port 4186
```

也可以用 `npm run dev -- --lan --port 4186`。原本的本機預覽可以繼續開著，只要使用不同連接埠。

終端機會列出「同 Wi-Fi 手機／平板」的網址。讓電腦與手機或平板連上同一個家庭 Wi-Fi，再把那個網址輸入 Safari 或 Chrome。請使用電腦的家庭網路 IPv4 位址；手機上的 `127.0.0.1` 指向手機自己，連不到這台電腦。試玩時，保持電腦與預覽程式開著。結束時在終端機按 `Ctrl+C`。

未加 `--lan` 時，仍只提供 `http://127.0.0.1:4173` 的電腦本機預覽。`--port` 或 `PORT` 環境變數可以指定連接埠；`--dist` 可以改為預覽已建置的 `dist`。

## 手機連不上時

- 確認兩台裝置都在同一個家庭 Wi-Fi，手機暫時關閉行動網路。訪客 Wi-Fi 若開啟裝置隔離，可能無法連到電腦。
- 確認網址與目前終端機列出的 IPv4 位址、連接埠一致。電腦換網路或重新取得位址後，舊網址可能不能使用。
- 如果 Windows 顯示 Node.js 的防火牆詢問，只在信任的私人家庭網路允許。這個指令不會自行修改防火牆，也不需要管理員權限。
- 如果仍連不上，由家長檢查電腦防火牆或路由器的裝置隔離設定。不要為試玩關閉整個防火牆。

這是同一家庭網路的 HTTP 預覽，沒有建立公開連結，也不能當成外網手機網址。終端機不會建議 Tailscale、VPN、虛擬網卡或公開 IP。LAN 模式只接受本機與私人 IPv4 來源。

## 進度在哪裡

每台裝置、每個瀏覽器，以及不同網址的護照紀錄各自儲存。例如電腦的 `127.0.0.1:4185` 與手機使用的家庭網路網址，不會共用同一本護照。換連接埠也會形成新的儲存位置。清除瀏覽器資料或使用不保留資料的瀏覽模式，可能清除紀錄。

這個預覽不提供帳號同步或離線保證。實體 iPhone／iPad Safari 與 Android 手機仍需由本人試玩；電腦以手機尺寸檢查版面、或從電腦連到 LAN 位址，都不能代替實體裝置驗證。

## 家長試玩清單

- 手機直向與平板橫向都能選車、開始旅程，沒有左右滑動才能看完整內容的情形。
- 在算術題先輸入一位、兩位數，試試清空、刪除與送出；題目與輸入區都保持看得見。
- 算到一半切到其他 App，再回來；再試重新整理頁面，確認畫面與進度符合預期。
- 完成旅程後先不領小禮物，重新打開護照，再領一份，確認不會少領或多領。
- 關閉電腦或預覽程式後，確認家長知道這個區域網路網址會暫停服務。

## 預覽提供的檔案

伺服器僅提供 `index.html`、`manifest.webmanifest`、`src`、`data`、`assets`、`docs`、`licenses` 中的靜態檔案，以及 `LICENSE`、`NOTICE`、`ASSET-LICENSE.md`、`PRIVACY.md`。不提供任意專案根目錄檔案、Git 資料、程式腳本、測試、套件設定或隱藏檔。網址中的上層路徑、Windows 特殊路徑與指向範圍外的連結也會被拒絕。這些限制同時適用於本機與 LAN 預覽。
