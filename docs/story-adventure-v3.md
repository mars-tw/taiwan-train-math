# 星光高鐵故事與新冒險 · v1.2.0

## 這次的體驗

孩子一打開首頁，就看到白色、香檳金與暖橘色的星光高鐵，沿山海軌道朝畫面下方慢慢行駛。它帶著一封金色的信，要送到海邊小站。看故事、點風景、開信，再親手完成故事裡的小任務。

星光高鐵是想像故事列車。真實台灣高鐵 700T、海外子彈列車與磁浮試驗車仍在原圖鑑，保留名稱、型號、來源與狀態，故事車不當作實車教材。

## 四段故事

| 段落     | 畫面與故事                   | 孩子的互動                         |
| -------- | ---------------------------- | ---------------------------------- |
| 森林出發 | 星光高鐵帶著信離開山林起點   | 播放、暫停、聽故事，看看白金色列車 |
| 經過山谷 | 小鳥提醒前方要接好軌道       | 點小鳥聽到文字回應，準備鋪軌任務   |
| 迎接海風 | 燈塔迎接列車，朋友開始分點心 | 點亮燈塔、準備和朋友分享           |
| 星光抵達 | 小站收到信，謝謝小站長陪伴   | 開信選任務，完成旅程拆紀念信封     |

完整行駛 36 秒，不自動循環，不限時作答。三個風景驚喜從一開始就開放，孩子可以自由點，無須等動畫播完。按「下一段」或四個段落按鈕會停在所選位置；暫停後可繼續，重播從起點出發。敘事朗讀需主動點「聽故事」，會暫停行駛讓孩子慢慢聽；初始頁面不播放聲音。

## 美術與動畫規格

- 背景採黃金時刻的山林、溪流、海岸與高架鐵道，文字區加森林綠漸層與半透明閱讀面板。
- 主列車用獨立透明 WebP，不以平移整張照片假裝列車行駛。車頭朝下，白色車身、深色玻璃、暖橘和金色細節；隨前進輕微放大，對應高角度透視。
- 根據背景的 cover 裁切與容器尺寸校正列車位置；桌面左右分區，手機文字在上、故事閱讀在場景下方。
- 小鳥回應輕微搖動、燈塔入口亮起、抵達時信封有柔和光圈。軌道接通後有單次小列車移動，拆禮物有短暫出現效果。
- 保留上一版山海任務地圖、暖陽／暮色、列車圖鑑及精選選車，並提供「直接選車玩遊戲」捷徑。
- 所有互動用實際按鈕，可鍵盤操作；段落有選中狀態，敘事僅換段時宣告，避免逐幀重複朗讀。

故事不在畫面、頁籤隱藏時不推進時間。切換頁面或開始遊戲會清掉動畫與觀察器，開啟家長設定／列車介紹會暫停。家長或系統開啟減少動畫時，停止自動行駛及裝飾動效，仍可手動讀完四段與玩所有任務。

## 三個新遊戲

| 遊戲         | 3–4 歲                   | 5–6 歲                  | 7–8 歲                        | 練習與驚喜                                                 |
| ------------ | ------------------------ | ----------------------- | ----------------------------- | ---------------------------------------------------------- |
| 路線小工程師 | 2 × 2，三段有效軌道      | 3 × 3，五段有效軌道     | 3 × 3，七段有效軌道、兩種路徑 | 每點一下轉 90 度，從左側起點接到右側小站；接通有列車到站   |
| 列車點心派對 | 兩位朋友，總量不超過 5   | 兩或三位，總量不超過 10 | 兩或三位，總量不超過 20       | 一份份分水果、搬回、重分；物品守恆，需全部分完且每位一樣多 |
| 山海尋寶     | 九個物件，找兩或三個目標 | 十二個物件，找兩至四個  | 十二個物件，找兩至五個        | 找星星、葉子或貝殼，找到留下記號；目標全找完出現驚喜信封   |

鋪軌的提示顯示參考路線，孩子仍需自己旋轉。分享提示建議輪流給每位一份，沒有直接填答案。尋寶提示會標出目標；錯點不扣分、不扣生命，同一物件只計一次。所有新任務都能單項練習或加入隨機旅程，沿用三站／五站與無倒數設計。

## 旅途禮物

每趟完成後，孩子可以親手按「打開紀念信封」。十二款包括星光信封、海邊燈塔、森林葉子、山谷雲朵、冒險車票、分享蘋果、青山徽章、唱歌小鳥、車站小鐘、雨後彩虹、海浪貝殼、小站星星。每款搭一句鼓勵或故事短句。

優先給尚未收藏的款式，十二款收齊後仍可玩與收禮物。不付費、不設稀有度、不鎖車、不設限時或每日登入獎勵。一次旅程只開一份；禮物 ID 存在本機護照，保留原有旅程與列車紀念章。關閉尚未拆的完成頁面不會影響既有集章。
