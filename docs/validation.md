# 驗證紀錄

## v1.1.0 — 2026-10-04

環境：Windows、Node.js 24、Codex 內建 Chromium。以 `node --test tests/*.test.mjs` 執行，8 組通過、0 失敗；`node scripts/build.mjs` 建立靜態網站。

- 既有 1,500 趟分齡隨機旅程檢查持續通過；另驗證 3,300 題新玩法的數量、圖形規律、跳數、時鐘、唯一選項與記憶卡可解性。
- 記憶狀態驗證：同卡不能重複翻、索引必須合法、錯配不能翻第三張、完成配對才得出正確答案。
- 驚喜旅程包含數數與所選列車辨識，其餘適齡任務隨機且不重複；100 個分散種子／年齡組涵蓋每種適齡玩法。
- 瀏覽器實際完成四種新玩法各一整趟：幼兒規律、裝箱、翻卡各三站，以及 7–8 歲時鐘五站（包含整點與半點）。
- 裝箱錯答仍能再試；貨物可搬回，20 箱時加 1 與加 5 均停用。翻卡錯配保留至手動重試，提示不直接完成配對。
- 390 × 844 測試首頁、登車證、20 箱畫面與八張記憶卡，沒有水平溢出。瀏覽器捲軸使可用內容寬為 375px，內容寬同為 375px。
- 地圖入口選站後有預覽；任務卡能直接開始。暖陽／暮色的選中狀態正確，關閉音效後進站鈴停用。
- 一般出發推進可進入題目；出發期間按返回首頁能取消。減少動畫偏好可直接出發，並遵守系統 reduced motion。
- 修正重新整理 `#departure` 深連結時的初始載入；跳到主要內容不再切換遊戲路由。
- 新版載入後原有三趟本機旅程與紀念章保留，四趟試玩增加至七趟；重載保留。未清除原紀錄。

以上為工程操作驗證。真實親子試玩、實體 Safari／Android 與語音聽感仍列於待辦。

## v1.0.0 初版驗證

日期：2026-10-03。環境：Windows、Node.js 24、Codex 內建 Chromium 瀏覽器。

## 自動測試

`npm test`：5 組通過、0 失敗。每種難度測試 500 種隨機種子，共 1,500 趟題目組合，檢查答案、數量範圍、選項唯一性、幼兒不出加減、排序及比較結果。

另逐條檢查列車 ID、圖片存在、官方來源、型號種類、識別題的同圖／同型號歧義、未來與試驗標示。損壞或禁止的儲存不阻止遊玩。`npm run build` 可建立靜態 dist。

## 瀏覽器操作驗證

- 桌面首頁、電影風背景、選車及圖鑑載入。
- 完成 3–4 歲、5–6 歲、7–8 歲各一趟完整旅程。
- 幼兒重複點同一位乘客只計一次；錯答可再試，正答能繼續。
- 上車與下車都先展示人數變化，完成前選項不可按。
- 幼兒三節排序、五節排序、較大連續數排序，取回車廂後可重排。
- 名稱配對、磁浮 L0 型號配對及左右票數比較可完成。
- 旅程完成後本機旅程數增加，相同列車不重複增加新章；重新整理保留紀錄。
- 390 × 844 手機尺寸檢查畫面，遊戲頁內容寬度與畫面寬度相同，沒有水平溢出。
- 家長「減少動畫」與「跨十挑戰」偏好在重新整理後保留。
- 清除紀錄先顯示第二次確認；「保留紀錄」取消後保有原護照。
- 返回相同首頁錨點也能離開完成畫面。

## 限制與下一步

這些是開發操作驗證，尚未替代 3–8 歲真實親子試玩。未測實體 iOS Safari、Android 裝置或中文語音的實際聽感。AI 插圖已檢查可用性，但不保證外觀細節精準；家族共用與保存車皆明示。
